# 💻 DevConf

DevConf is a modern developer conference landing page designed to showcase conference speakers, pricing plans, venue information, and social links. The project focuses on creating a clean, professional, and responsive conference website using HTML and CSS.

## 🌐 Live Website

[Visit DevConf](https://dev-conf-a01.vercel.app/)

## 📸 Preview

## ✨ Features

- 🎤 **Speakers Section** — Displays conference speakers with their roles and organizations.
- 💳 **Pricing Plans** — Includes Standard, Pro, and Team ticket options.
- 📍 **Venue Information** — Shows the event location, date, time, parking information, and directions.
- 🧭 **Navigation Bar** — Provides quick navigation to different sections of the website.
- 🔗 **Social Links** — Includes links to Facebook, X, LinkedIn, and GitHub.
- 🎨 **Modern UI** — Clean layout with cards, buttons, typography, and a professional color scheme.
- 🔄 **Smooth Scrolling** — Navigation links smoothly scroll to page sections.

## 🛠️ Technologies Used

- **HTML5** — Used to structure the website.
- **CSS3** — Used for styling, layout, cards, buttons, and responsive design.
- **Google Fonts** — Inter font family for typography.
- **Font Awesome** — Used for social media icons.
- **CSS Grid & Flexbox** — Used for creating page layouts.
