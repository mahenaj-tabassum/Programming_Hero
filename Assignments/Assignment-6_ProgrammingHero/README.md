# FitLog

A modern dark-themed workout tracking web application. It is built with Next.js.

# Live Demo

https://fitlog-workout-website.vercel.app/


---
# Technologies Used

- Next.js (App Router)

- React

- TypeScript

- Tailwind CSS

- Lucide React

- React Toastify

# Key Features

- Browse all workouts from the FitLog API in a responsive workout library.
- View detailed workout information.

- Add workouts to Today's Plan with a maximum limit of five exercises.

- Save workouts for later with duplicate prevention and toast notifications.

- Live dashboard showing Exercises, Minutes, and Calories for today's plan.

- Custom 404 page for invalid routes.
