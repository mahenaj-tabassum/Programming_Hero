# User Management System

A full-stack CRUD application built with Next.js, React, TypeScript, Express.js, and MongoDB.

## 🌐 Live Demo

- **Frontend:** https://crud-operation-client-side.vercel.app/
- **Backend API:** https://crud-operation-backend-api.vercel.app/

## ✨ Features

- View all users and individual user details
- Create, update, and delete users
- REST API integration
- Responsive UI with a dark green and lime-green color palette

## 🛠️ Tech Stack

**Frontend:** Next.js, React, TypeScript, Tailwind CSS, shadcn/ui

**Backend:** Node.js, Express.js, MongoDB

## 🔗 API Endpoints

| Method | Endpoint     | Description      |
| ------ | ------------ | ---------------- |
| GET    | `/users`     | Get all users    |
| GET    | `/users/:id` | Get a user by ID |
| POST   | `/users`     | Create a user    |
| PATCH  | `/users/:id` | Update a user    |
| DELETE | `/users/:id` | Delete a user    |

## 🎨 Color Palette
