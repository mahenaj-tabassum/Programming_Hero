# 🏏 BPL Dream 11

A responsive **React + TypeScript** web application inspired by the Bangladesh Premier League (BPL), where users can build their dream cricket team by selecting players within a coin budget.

🔗 **Live Demo:** https://bpl-dream-11-zeta.vercel.app/

---

## ✨ Features

- 🏏 Build your own BPL Dream Team
- 💰 Coin-based budget system
- 🚫 Prevent duplicate player selection
- ⚠️ Validation for insufficient coins
- ❌ Remove players from the selected team
- 📊 Real-time selected player counter
- 💵 Dynamic total cost calculation
- 📱 Fully responsive design
- 🔔 Toast notifications for user actions

---

## 🛠️ Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- DaisyUI
- React Toastify
- Lucide React

---

## 🚀 How It Works

1. Users start with a fixed number of coins.

2. Browse the available BPL players.

3. Click Choose Player to add a player.

4. The player's price is deducted from the available coins.

5. Duplicate selections are prevented.

6. Remove players anytime from the selected team.

7. React State updates the UI instantly.

## 🧠 React Concepts Practiced

This project helped me practice multiple React concepts together while building a complete application.

- **Component-Based Architecture** – Built reusable UI components.
- **JSX** – Created dynamic user interfaces using JSX syntax.
- **Props** – Passed data between parent and child components.
- **State Management (`useState`)** – Managed player selection, coins, and UI updates.
- **Event Handling** – Responded to user interactions like button clicks.
- **Conditional Rendering** – Switched between available and selected player views.
- **List Rendering (`map()`)** – Displayed player cards from data.
- **Immutable State Updates** – Updated arrays without mutating state.
- **Lifting State Up** – Shared state across multiple components through a parent component.
- **Data Fetching** – Loaded player data from a JSON file.
- **TypeScript Interfaces** – Ensured type safety for props and player data.
- **Array Methods (`map`, `filter`, `reduce`)** – Processed and managed application data efficiently.

# ⚙️ Installation

Clone the repository and run it locally.

## Clone repository

```
git clone https://github.com/mahenaj-tabassum/Programming_Hero/tree/main/React_JS/Module_31
```

## Go to project folder

```
cd bpl-dream-11
```

## Install dependencies

```
npm install
```

## Start development server

```
npm run dev
```

## Build for production:

```
npm run build
```
